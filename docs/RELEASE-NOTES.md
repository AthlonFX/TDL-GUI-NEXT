# TDL-GUI-NEXT 1.0.0

Windows 10/11 x64 免安装版。下载后完整解压，双击 TDL-GUI-NEXT.exe。不要只复制 EXE。内含 Electron、Node.js、tdl 和 FFmpeg，无需另装这些组件。

首次启动默认使用系统代理和 Windows 的“下载”文件夹。扫码登录；启用 Telegram 二步验证的账号需要输入密码。

现有用户的登录、设置和记录保留在原资料目录。升级前退出软件，将新版解压到新目录即可；不要将个人缓存、登录库和下载文件上传或分享。

- TDL-GUI-NEXT 源码许可：AGPL-3.0-only。
- tdl：iyear/tdl 0.20.4，AGPL v3，作为独立进程调用。
- 本项目不是 tdl 或 Telegram 官方客户端。
- 此次打包不包含作者账号、个人配置、聊天记录、缩略图缓存或下载文件。
- 本次附件包含工作台源码包、免安装包、SHA256SUMS.txt 和 tdl 对应版本源码包。
- FFmpeg 保持现有版本；对应源码和依赖构建材料尚未核实完整，本次不声明已完成全部二进制再分发材料核查。

完整功能和限制见 CHANGELOG.md；组件与源码获取记录见 THIRD-PARTY-NOTICES.md。

项目源码：[AthlonFX/TDL-GUI-NEXT](https://github.com/AthlonFX/TDL-GUI-NEXT)。本版本源码标签：[v1.0.0](https://github.com/AthlonFX/TDL-GUI-NEXT/tree/v1.0.0)。
