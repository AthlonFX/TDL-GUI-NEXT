# TDL-GUI-NEXT 使用说明

## 启动与登录

解压整个免安装文件夹，双击 `TDL-GUI-NEXT.exe`。程序包含所需运行文件，不依赖 Codex，也不需要用户另装 Node.js 或 tdl。

点击账号旁边的加号或“账号登录”，为新账号填写名称，扫码登录。账号启用 Telegram 二步验证时，密码框会自动启用。成功后可在账号下拉框切换。已有 tdl 登录状态可以继续使用。

## 浏览与下载

1. 按网络环境在设置中选择不使用代理、系统代理或自定义代理。可测试当前填写的连接配置，无需先保存。
2. 左侧选择会话，按时间显示消息。一直向上滚动加载更早历史；“我的收藏 / Saved Messages”固定显示。会话右侧可设置本机置顶，按账号分别保留。
3. 图片和视频封面自动加载可见区域的独立缩略图，不会为了预览先下载完整视频。没有独立缩略图的消息可能只能显示小图或文件卡片。
4. 使用勾选框选择文件，也可从消息右侧空白处按住鼠标左键上下拖动多选；接近边缘自动滚动，Esc 取消本次拖选。
5. 右侧选择本次下载位置，再下载所选文件。支持图片、视频、压缩包、文档和其他附件。
6. 也可以粘贴自己有权访问的具体消息链接下载。能否读取某个文件取决于账号权限、Telegram 及当前 tdl 的支持情况。

## 下载位置

首次使用默认保存到 Windows 的“下载”文件夹，使用系统实际位置，包含系统重定向后的路径。

- 右侧“选择文件夹”修改本次下载位置；“将当前位置设为默认”保存该位置。
- 设置中的默认下载位置可输入或选择文件夹，更改后自动保存。
- “恢复默认下载位置”立即恢复为系统“下载”文件夹并保存，无需额外操作。
- “打开下载位置”用资源管理器打开设置中当前填写的位置；尚未存在的文件夹会先创建，不会移动已有下载。
- 恢复默认只影响之后新建的下载任务，现有任务及原先下载的文件仍在原位置。

## 日期与外观

“日期筛选”按起止日期限制读取范围；“日期跳转”定位到某天附近，之后仍可向上下两个方向浏览。当天没有消息时定位到附近可用消息。“回到最新”恢复近期消息浏览。

点击右上角“主题”直接打开外观设置，可选择跟随系统、浅色或深色。设置中的主题色支持预设和自选，立即生效并自动保存。

## 代理与限速

代理支持不使用代理、跟随系统代理和自定义代理。自定义支持 HTTP、HTTPS、SOCKS5。首次使用默认跟随系统代理。

下载速度支持 KB/s、MB/s，0 为不限速。更改后自动保存，立即对正在下载和后续任务生效，所有下载连接共享上限。代理设置对下次连接生效。

## 缓存、记录和数据

- 默认缩略图缓存位于 EXE 同级的 `cache\previews`。
- 设置中可查看大小、打开缓存目录、选择位置、恢复默认或清理缓存。自选位置会创建 `tdl-thumbnail-cache` 专用目录，切换时校验并迁移已有缓存。
- 清理缓存不删除登录信息、下载记录或已下载文件；继续浏览时会重新加载缩略图。
- “清除记录”只清理当前账号已结束的任务记录，不删除已下载文件，也不取消正在运行或等待中的任务。
- 设置、账号列表、置顶和记录位于 `%APPDATA%\TDLWorkbenchDesktop\workbench`。改名后保留原路径以兼容已有数据。
- tdl 登录信息默认位于 `%USERPROFILE%\.tdl`，如配置 `TDL_STORAGE` 则使用指定存储位置。

关闭窗口时若仍有下载或登录任务，可选择后台继续或退出并暂停。重启后可重试未完成任务。不要同时用多个独立工作台操作同一账号。

不要分享登录目录、个人设置、缓存、日志、真实聊天截图或旧版备份。发布软件请从干净源码构建，避免将个人缓存打包。

本软件为第三方桌面工作台，下载能力基于 iyear/tdl（GNU AGPL v3），并非 Telegram 或 tdl 官方客户端。不包含转发、建站或自动化规则。

## 界面与自动保存

- 设置中的下载位置、代理和限速更改后自动保存；输入暂停时保存文本，切换选项或选择文件夹立即保存。顶部会显示保存状态，无效输入保留上次有效设置。
- 主题按钮直达外观设置，深浅模式与主题色使用平滑颜色过渡，遵循系统减少动态效果设置。
- 主界面“取消选择”一次清空所有勾选，包含搜索后暂时隐藏的选择。
- “将当前位置设为默认”为完整按钮；下载任务区不再显示全局打开默认文件夹按钮。

## 退出账号和托盘

账号管理中的“退出登录”会注销当前 Telegram 登录会话，成功后可重新扫码登录；其他账号及本地下载历史保留。该账号有等待或运行的下载、登录任务时，需先结束任务。

右下角托盘图标在软件运行时常驻，点击可恢复主窗口。右上角关闭时可选择最小化到托盘或退出，并勾选记住选择；设置中的“窗口与托盘”可以随时更改关闭行为。最小化到托盘时下载继续，真正退出会停止当前任务。
